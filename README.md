# The Legend of Trump · 白宫奇遇记

基于 **React 19 + Three.js + React Three Fiber + TypeScript + Vite** 的可玩低多边形冒险游戏。

参考提供的视频中的金发西装角色、第三人称视角、白宫外景与办公室、爱心／翡翠／小地图界面，制作了一个可独立运行的冒险章节。标题页参考用户提供视频的剑盾 Logo、金色字形和暗纹背景。人物通过 Blender MCP 重新建模并导出 GLB，场景与音效由代码生成；没有打包整段原视频、原游戏模型或原游戏音乐。

## 启动

需要 Node.js 22.12+（或 24/26）及支持 WebGL 2 的现代浏览器。

```bash
npm ci
# 在本机工作区自动调用端口管理器分配端口：
npm run dev
# 在其他机器上，明确指定一个空闲端口：
PORT=5173 npm run dev
```

终端会打印实际访问地址。当前开发环境使用端口管理器的 `worktree-frontend` 池，首次验证地址为 `http://127.0.0.1:4439/`。启动脚本不覆盖已有监听进程。

```bash
npm run build
PORT=5173 npm run preview
```

`dist/` 是可部署的静态站点。资源使用相对路径，可放在子目录中。游戏无需后端；Google Fonts 不可用时使用系统字体回退。

## 玩法

1. 在南草坪收集 **8 枚翡翠**。沿喷泉两侧探索，陶罐中也有翡翠。
2. 挥剑击碎陶罐，每个陶罐获得 2 枚翡翠。木箱也可破坏；发条守卫需要三次命中，会先蓄力再攻击，可用盾牌正面格挡或闪避；受击会中断蓄力、后仰硬直并被击退。
3. 集齐后到白宫大门前交互，进入椭圆形办公室。
4. 走近书桌并签署冒险宣言，完成章节。

三颗爱心耗尽后可以重试；暂停时模拟停止，窗口失焦自动暂停。当前为单章节、单次会话游戏，无自动存档。

| 操作            | 键位                                          |
| --------------- | --------------------------------------------- |
| 按镜头方向移动  | WASD / 方向键                                 |
| 鼠标视角 / 缩放 | 左键攻击并锁定鼠标 / 滚轮；无法锁定时中键拖动 |
| 跳跃 / 冲刺     | Space / 按住 Shift                            |
| 拔剑攻击        | 鼠标左键 / J                                  |
| 举盾防御        | 按住鼠标右键 / F                              |
| 闪避 / 锁定目标 | Ctrl 或 K / Q                                 |
| 交互            | E / 点击屏幕交互提示                          |
| 复位视角 / 暂停 | R / Esc（同时释放鼠标）                       |

剑与盾不用时背在角色身后，攻击时剑切换到右手，格挡时盾切换到左手，连招衔接期间保持手持，结束后自动背回。冲刺、跳跃、攻击、闪避和承受格挡消耗体力，停止消耗后恢复。

连续点击左键、按 J 或点击手机攻击按钮，可以打出 **横斩 → 反手斩 → 下劈**。起手后约 0.08 秒即可预输入下一式，每次只缓存一式；前两式收招后还有 0.26 秒衔接窗口，停顿过久从第一式重来。第三式结束有额外收招，不能无限连发。三式分别消耗 8 / 9 / 12 体力；体力不足不会强制出招，闪避会中断当前连招。

动作由肩、肘、腕、腰和膝关节协同驱动，剑绑定右手腕，盾绑定左手腕。命中时有短促停顿、剑光、敌人闪亮与受击后仰；普通斩击硬直约 0.56–0.60 秒，下劈约 0.95 秒。击退受场景碰撞约束，敌人硬直结束后恢复行动，最后一击有倒地退场过程。

左键第一次点击场景就会攻击，同时申请鼠标锁定；浏览器拒绝锁定时仍可攻击。左键连点与 J 使用同一套连招逻辑，暂停菜单或其他界面按钮不会触发攻击。

暂停菜单的「视角与鼠标设置」支持镜头距离 5–14（默认 9.5）、垂直视野 55–80°（默认 60°）、灵敏度 0.4–2 倍，以及垂直反转。滚轮也能调距离，设置保存在本机浏览器；可一键恢复默认。竖屏会自动扩展垂直视野以保持横向可见范围。

相机遇墙及时收缩、离墙平滑恢复；先尝试抬高镜头越过低家具，守卫不参与相机阻挡。墙边无法保持距离时角色淡出，避免身体遮住画面，同时保留墙体避障。实现参考了 [Epic 的第三人称 Camera / Spring Arm 说明](https://dev.epicgames.com/documentation/en-us/unreal-engine/camera-components?application_version=4.27)，具体距离和视野按本项目场景调整。

手机和平板使用左侧虚拟摇杆移动、右侧空白区域滑动视角，以及攻击、跳跃、闪避、锁定、冲刺和防御按钮；支持多指同时操作。冲刺与防御需要按住，松手或触控取消即释放。

花园新增宝箱、开门机关、草药、告示牌、休息长椅和可破坏木箱。宝箱与草药只能领取一次，机关开启花园铁门。碰撞包含建筑、树木、喷泉、花坛、家具、道具和守卫；角色支持跳上平台、边缘坠落和墙边滑动，攻击与交互检查遮挡，相机遇墙缩短距离。

## 项目结构

- `src/game/simulation.ts`：独立于渲染器的移动、碰撞、战斗、收集和任务状态机。
- `src/game/combat.ts`：三段攻击的共享命中时序与关节姿势插值。
- `src/game/input.ts`：键盘、鼠标锁定、摇杆与失焦处理。
- `src/game/world.ts` / `collision.ts`：共享交互位置、碰撞体、分步滑动、落地与射线遮挡。
- `src/components/InteractiveProps.tsx`：宝箱、机关与采集物模型及状态动画。
- `src/game/audio.ts`：用户手势激活后的 Web Audio 合成音效。
- `src/components/World.tsx`：白宫建筑、花园、喷泉与办公室。
- `src/components/Character.tsx`：Blender GLB 加载，以及行走、挥剑和坐姿书写动画。
- `src/components/Scene.tsx`：R3F 场景、相机、实体同步及模拟步进。
- `src/components/Hud.tsx`：DOM 界面、小地图及触屏操作。
- `src/App.tsx`：标题、暂停、指南、对话和结算。

高频游戏状态保存在模拟实例中，DOM 以低频率刷新，角色和相机通过 `useFrame` 同步。模拟对大帧间隔分步处理，避免穿透与明显的低帧率减速。为了方便本地端到端测试，仅开发环境暴露 `window.__game`、`window.__scene` 和 `window.__camera`，生产构建不暴露。

## 验证

```bash
npm test
npm run build
# 先在另一终端启动开发服务器；默认使用本机 Chrome：
GAME_URL=http://127.0.0.1:4439 npm run test:e2e
```

- 单元测试覆盖镜头相对移动、连续碰撞、跳台落地、相机避障、方向与遮挡攻击、机关与一次性奖励、盾牌和闪避、体力、通关与重开。
- Playwright 覆盖剑盾背负／手持切换、跳跃、鼠标锁定与格挡、相机避墙、互动与完整通关。
- 移动端验证 390 × 844 视口，三指同时移动、冲刺与转动视角，防御取消清理及无横向溢出。
- 测试中用开发接口设置中间场景位置，随后通过真实输入与模拟验证交互，并非全程自动寻路。
- 截图保存在 `artifacts/`。测试配置默认使用本机 Chrome，也可设置 `BROWSER_CHANNEL=chromium` 并先执行 `npx playwright install chromium`。

视频中没有展示完整收集和战斗规则；陶罐奖励、发条守卫、翡翠门槛和通关条件是本项目为构成可玩流程添加的设计。画面按照视频改为饱和蓝天、低多边形人物和 N64 风格的红心、绿／蓝／黄色操作按钮。本项目为非官方创作。

## Blender 模型与素材

- `assets/blender/trump-n64.blend`：独立的人物建模源文件。
- `assets/blender/build_trump.py`：可复现的 Blender 建模脚本，包含棱面头部、金发、面部五官、西装红领带、旗帜胸针和肩、肘、腕、髋、膝及腰部关节层级。
- `public/models/trump-n64.glb`：约 97 KB，13 个网格对象、约 1,318 个三角形，保留可动画的命名轴；无外部纹理依赖。
- `assets/blender/adventure-props.blend` / `build_adventure_props.py`：独立剑、盾、宝箱、机关、木箱与草药源文件及生成脚本。
- `public/models/hero-*.glb` / `adventure-*.glb`：六个轻量模型，宝箱与机关保留可动画轴。
- `public/title-screen.jpg`：从用户提供视频第 2 秒提取的标题画面，作为静态标题页素材。

重建时在 Blender 中设置 `TRUMP_PROJECT_DIR` 环境变量为项目绝对路径，再运行建模脚本。脚本创建独立场景，仅导出当前人物场景，保留现有 Blender 工程。随后在项目目录执行 `npm run assets:optimize`，通过 glTF Transform 去重、焊接和清理。

5 项浏览器测试通过，覆盖键鼠、手机多点触控、通关及三段关节连招。21 项单元／资产测试覆盖连招输入缓存、体力与取消、单次命中、敌人硬直恢复和终结技。测试包含无瞬移的完整草坪路线验证；浏览器用开发接口定位部分测试场景，再以真实键鼠和多点触控操作验证。
