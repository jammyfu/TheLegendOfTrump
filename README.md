# The Legend of Trump · 白宫奇遇记

[简体中文](README.md) · [繁體中文（香港）](README.zh-HK.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

基于 **React 19 + Three.js + React Three Fiber + TypeScript + Vite** 的可玩低多边形冒险游戏。

参考提供的视频中的金发西装角色、第三人称视角、白宫外景与办公室、爱心／翡翠／小地图界面，制作了一个可独立运行的冒险章节。标题页参考用户提供视频的剑盾 Logo、金色字形和暗纹背景。人物通过 Blender MCP 重新建模并导出 GLB，场景与音效由代码生成；没有打包整段原视频或原游戏模型。配乐包含 Suno 生成曲目及可选的《时之笛》原版曲目，来源见 [音频说明](public/audio/README.md)。

## 启动

需要 Node.js 22.12+（或 24/26）及支持 WebGL 2 的现代浏览器。

```bash
npm ci
# 在本机工作区自动调用端口管理器分配端口：
npm run dev
# 在其他机器上，明确指定一个空闲端口：
PORT=5173 npm run dev
```

终端会打印实际访问地址。当前开发环境使用端口管理器的 `worktree-frontend` 池，首次验证地址为 `http://127.0.0.1:4439/`。启动脚本不覆盖已有监听进程。

```bash
npm run build
PORT=5173 npm run preview
```

`dist/` 是可部署的静态站点。资源使用相对路径，可放在子目录中。游戏无需后端；Google Fonts 不可用时使用系统字体回退。

## 设置与语言

标题页和暂停菜单的「设置」支持简体中文、English、日本語、한국어，以及总声音开关、音乐／音效独立音量、Suno／时之笛配乐来源和镜头选项。设置自动保存在本机浏览器，游戏进度不随之存档。两套配乐均读取 `public/audio/` 内的本地文件。

## 玩法

1. 在南草坪收集 **8 枚翡翠**。沿喷泉两侧探索，陶罐中也有翡翠。
2. 挥剑击碎陶罐，每个陶罐获得 2 枚翡翠。木箱也可破坏；发条守卫需要三次命中，会先蓄力再攻击，可用盾牌正面格挡或闪避；受击会中断蓄力、后仰硬直并被击退。
3. 集齐后到白宫大门前交互，进入椭圆形办公室。
4. 打开东侧旅行宝箱获得冒险弓和 16 支箭；花园宝箱另提供 12 支箭。按 X 切换剑盾 / 弓箭，长按左键拉弓、松开射击，右键精瞄。
5. 击败室内 Boss「铁甲统领」：金色横扫可正面格挡，红色重砸需要闪避，扩散冲击波可以跳过。半血后进入更快的过载阶段；12 / 6 血阶段各召唤一波卫兵，2.4 秒预警，每波最多两名，两波至少相隔 14 秒。远距离也会释放冲击波。
6. 胜利后走近书桌并签署冒险宣言，完成章节。

三颗爱心耗尽后可以重试；室内失败会在 Boss 房间入口恢复满血重新挑战，保留翡翠；暂停时模拟停止，窗口失焦自动暂停。当前为单章节、单次会话游戏，无自动存档。

剑与盾不用时背在角色身后，攻击时剑切换到右手，格挡时左手举盾、右手保持持剑，连招衔接期间保持手持，结束后自动背回。冲刺、攻击、闪避和承受格挡消耗体力，停止消耗后恢复。

连续点击左键、按 J 或点击手机攻击按钮，可以打出 **下劈 → 左向右横斩 → 右向左横斩**。起手后约 0.035 秒即可预输入下一式，每次只缓存一式；前两式收招后还有 0.34 秒衔接窗口，停顿过久从第一式重来。第三式结束有额外收招，不能无限连发。三式分别消耗 8 / 9 / 12 体力；体力不足不会强制出招，闪避会中断当前连招。

动作由肩、肘、腕、腰和膝关节协同驱动，剑绑定右手腕，盾绑定左手腕。命中时有短促停顿、剑光、敌人闪亮与受击后仰；普通斩击硬直约 0.56–0.60 秒，第三式横斩约 0.95 秒。击退受场景碰撞约束，敌人硬直结束后恢复行动，最后一击有倒地退场过程。

左键第一次点击场景就会攻击，同时申请鼠标锁定；浏览器拒绝锁定时仍可攻击。左键连点与 J 使用同一套连招逻辑，暂停菜单或其他界面按钮不会触发攻击。

暂停菜单的「视角与鼠标设置」支持镜头距离 5–14（默认 9.5）、垂直视野 55–80°（默认 60°）、灵敏度 0.4–2 倍，以及垂直反转。滚轮也能调距离，设置保存在本机浏览器；可一键恢复默认。竖屏会自动扩展垂直视野以保持横向可见范围。

相机遇墙及时收缩、离墙平滑恢复；先尝试抬高镜头越过低家具，守卫不参与相机阻挡。墙边无法保持距离时角色淡出，避免身体遮住画面，同时保留墙体避障。实现参考了 [Epic 的第三人称 Camera / Spring Arm 说明](https://dev.epicgames.com/documentation/en-us/unreal-engine/camera-components?application_version=4.27)，具体距离和视野按本项目场景调整。

手机和平板使用左侧虚拟摇杆移动、右侧空白区域滑动视角，以及攻击、跳跃、闪避、锁定、冲刺和防御按钮；支持多指同时操作。冲刺与防御需要按住，松手或触控取消即释放。

花园新增宝箱、开门机关、草药、告示牌、休息长椅和可破坏木箱。宝箱与草药只能领取一次，机关开启花园铁门。碰撞包含建筑、树木、喷泉、花坛、家具、道具和守卫；角色支持跳上平台、边缘坠落和墙边滑动，攻击与交互检查遮挡，相机遇墙缩短距离。

弓箭每次消耗 1 支箭与 10 体力，0.85 秒满弓，射击间隔至少 0.48 秒。普通箭伤害 1，满弓伤害 2；Boss 只有收招或召唤时承受满弓额外伤害。飞箭用连续线段检测命中，墙与家具能挡箭。倒下的守卫掉落 3 支箭和体力补给；室内重试至少恢复 12 支箭。箭矢用尽仍可切回剑盾完成战斗。

默认自动锁敌：剑盾在 12 米内、弓箭在 22 米内、室内剑盾在 18 米内优先锁定视野中的可见敌人；5 米内的背后威胁也能捕获。已有目标保持稳定，Q 解除后可自由观察 4 秒，主动攻击立即恢复辅助锁定。锁定准星跟随敌人胸口并显示生命值，Tab 或顶部按钮切换目标，目标死亡后选择附近存活目标。鼠标转动不会误解除锁定，距离变化有缓冲；瞄准贴身敌人时人物半透明，避免挡住目标。手机使用武器切换按钮以及“拉弓·射箭”按钮，右侧“精瞄”替代持弓时的防御。

白宫室内扩至约 37 × 36，家具保持正常比例，补充柱头、柱槽、墙板、肖像、书柜、旗帜与顶部格栅；中央留出 Boss 与卫兵的战斗空间。

## 项目结构

- `src/game/simulation.ts`：独立于渲染器的移动、碰撞、战斗、收集和任务状态机。
- `src/components/RangedCombat.tsx`：屏幕锁定准星、飞箭、召唤预警和补给显示。
- `src/game/combat.ts`：三段攻击的共享命中时序与关节姿势插值。
- `src/game/input.ts`：键盘、鼠标锁定、摇杆与失焦处理。
- `src/game/world.ts` / `collision.ts`：共享交互位置、碰撞体、分步滑动、落地与射线遮挡。
- `src/components/InteractiveProps.tsx`：宝箱、机关与采集物模型及状态动画。
- `src/game/audio.ts`：用户手势激活后的 Web Audio 合成音效。
- `src/components/World.tsx`：白宫建筑、花园、喷泉与办公室。
- `src/components/Character.tsx`：Blender GLB 加载，以及行走、挥剑和坐姿书写动画。
- `src/components/Scene.tsx`：R3F 场景、相机、实体同步及模拟步进。
- `src/components/Hud.tsx`：DOM 界面、小地图及触屏操作。
- `src/App.tsx`：标题、暂停、指南、对话和结算。

高频游戏状态保存在模拟实例中，DOM 以低频率刷新，角色和相机通过 `useFrame` 同步。模拟对大帧间隔分步处理，避免穿透与明显的低帧率减速。为了方便本地端到端测试，仅开发环境暴露 `window.__game`、`window.__scene` 和 `window.__camera`，生产构建不暴露。

## 铁甲统领与椭圆厅

先生成 [敌人与室内概念图](assets/concepts/enemies-and-oval-arena.png)，再用 Blender MCP 制作可动画的守卫、铁甲统领，以及胡桃木地板、象牙色墙板、落地窗、酒红窗帘、金边地毯和家具。中央保留战斗空间；书柜、沙发、柱子与书桌都有对应碰撞体。

- 源文件：`assets/blender/enemies-arena.blend`；生成脚本：`assets/blender/build_enemies_arena.py`。
- 模型：`palace-sentinel.glb`、`iron-chancellor.glb`、`oval-arena.glb`，分别约 59、69、837 KB。
- 普通敌人保留受击硬直；Boss 蓄力时有霸体、收招时有进攻破绽，终结技能造成更强硬直。Boss 战支持锁定、血条、地面预警与失败重试。
- 持剑待机和格挡时剑刃保持直立，攻击期间由关节动作驱动。
- 直升机有持续发动机和旋翼拍击合成音效，随接近／远离淡入淡出，跳过片头时静音。落地开门时伸出登机梯，梯子就位后人物下机，离开前收梯关门。

![椭圆厅 Boss 战](artifacts/oval-boss-arena.png)

室内大厅现约 30 × 28 米，长宽比初版扩大 65%，家具保持原尺寸并向周边移动。室内镜头在个人距离设置基础上增加 1.5 米、视野增加 5°；焦点向前偏移，锁定 Boss 时平滑取双方之间的位置，减少人物遮挡与近战转向突变。家具、墙体、入口、书桌交互、小地图和结算镜头已同步调整。

按住鼠标左键、J 或手机「攻击」：先立即出刀，再进入蓄力。蓄满 1.2 秒会亮起金色光环并响起提示音，松开释放 360° 旋转斩；消耗 26 体力，半径 3.8 米，普通敌人与 Boss 各受到一次 2 点伤害。配有聚拢光点、蓄力进度、双层环形剑光和击退火花；攻击仍检查墙体遮挡。提前松开、受击、闪避、跳跃、暂停或触控取消会取消蓄力。

### 战斗性能

静态围栏、路灯及道具按材质合并绘制；宝箱盖和机关轴单独处理，碰撞数据不变。HUD 更新不再触发整个 Three 场景的 React 重绘。阴影贴图使用 1024²，3D 渲染分辨率在持续低帧率时从 1.0 降至最低 0.7，稳定后恢复；UI 文字不受影响。

锁敌每 0.2 秒搜索一次，已有目标不重复搜索。自动锁敌不会透墙获取目标，保留 Tab 手动换敌和距离释放缓冲。

### 镜头安全与跳起翻滚

Q 解除敌人锁定时停止鼠标视角捕获；重新点击“启用鼠标视角”、点击场景攻击或按中键拖动可主动恢复。延迟返回的 Pointer Lock 请求不能重新开启已解除的视角。

奔跑时按 Space（手机跳跃键）触发跳起翻滚；锁定敌人时，新按下 WASD／方向键或重新推动摇杆触发定向翻滚。按住同一方向不会连续自动翻滚，Ctrl／K／手机闪避键也可直接翻滚。每次消耗 24 体力，动作 0.55 秒、无敌 0.22 秒，空中不能再次启动；普通探索跳跃保留。

弓箭每次命中造成 1 点伤害，满蓄力不再造成双倍伤害；每箭消耗 14 体力，冷却 0.7 秒，满蓄力受击硬直降至 0.25 秒。Boss 也不再受到蓄力箭的双倍伤害。

直升机过场从机身外侧衔接人物视角；最终镜头位置在插值后重新检查碰撞，包含机体安全体积和室内墙体，并为近裁剪面保留间距。人物贴近镜头时，身体和装备统一淡出，过场同样适用。
