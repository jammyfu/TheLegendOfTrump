# The Legend of Trump · 백악관 모험

[简体中文](README.md) · [繁體中文（香港）](README.zh-HK.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

**React 19 + Three.js + React Three Fiber + TypeScript + Vite**로 만든 플레이 가능한 로우 폴리 어드벤처 게임입니다.

제공된 영상의 금발 정장 주인공, 3인칭 카메라, 백악관 정원과 집무실, 하트·보석·미니맵을 참고하여 독립적인 모험 챕터를 제작했습니다. 타이틀은 검과 방패 문양, 금색 글자, 무늬 배경을 사용합니다. 캐릭터와 장비는 Blender MCP로 새로 제작하여 GLB로 내보냈습니다. 비공식 작품이며 원본 영상 전체나 원작 게임 모델을 포함하지 않습니다. 음악은 Suno 생성 곡과 선택 가능한 《시간의 오카리나》 원본 곡을 포함합니다. [음원 출처](public/audio/README.md)를 확인하세요.

![타이틀 화면](artifacts/title-desktop.png)

## 실행

Node.js **22.12 이상**(또는 24/26)과 WebGL 2를 지원하는 최신 브라우저가 필요합니다.

```bash
npm ci
# 설정된 로컬 작업 환경에서는 포트 관리자를 사용합니다:
npm run dev
# 다른 컴퓨터에서는 사용 가능한 포트를 지정하세요:
PORT=5173 npm run dev
```

실제 접속 주소는 터미널에 표시됩니다. 원래 개발 환경에서는 `worktree-frontend` 포트 풀을 사용하며 최초 확인 주소는 `http://127.0.0.1:4439/`였습니다. 실행 스크립트는 기존 포트 사용 프로세스를 종료하거나 대체하지 않습니다.

```bash
npm run build
PORT=5173 npm run preview
```

`dist/`를 정적 사이트로 배포할 수 있으며 하위 경로 배포도 지원합니다. 백엔드는 필요하지 않습니다. Google Fonts를 불러올 수 없으면 시스템 글꼴을 사용합니다.

## 설정 및 언어

타이틀 또는 일시 정지 메뉴의 **설정**에서 **简体中文 / English / 日本語 / 한국어**를 선택할 수 있습니다. 전체 소리 켜기·끄기, 음악과 효과음의 개별 음량, Suno／시간의 오카리나 음악 선택, 카메라 설정을 지원합니다. 설정은 현재 브라우저에 저장되지만 모험 진행 상황은 저장하지 않습니다. 두 음악 모드 모두 `public/audio/`의 로컬 파일을 재생합니다.

## 게임 방법

1. 남쪽 잔디밭과 분수 주변을 탐험하며 **보석 8개**를 모으세요. 항아리에도 보석이 있습니다.
2. 항아리를 부수면 보석 2개를 얻으며 나무 상자도 파괴할 수 있습니다. 경비병은 준비 동작 후 공격합니다. 정면에서 방어하거나 굴러 피하세요. 일반 경비병은 공격을 받으면 행동이 끊기고 뒤로 밀립니다.
3. 보석을 모은 뒤 백악관 정문에서 상호작용하여 집무실로 들어가세요.
4. 동쪽 보급 상자에서 활과 화살 16개, 정원 상자에서 화살 12개를 얻습니다. X로 무기를 바꾸고 공격을 길게 눌러 활을 당긴 후 놓아 발사합니다. 오른쪽 클릭을 누르면 정밀 조준합니다.
5. 실내 보스 **철갑 사령관**을 물리치세요. 금색 휩쓸기는 방어, 빨간 망치 강타는 회피, 충격파는 점프로 대응합니다. 체력이 절반 이하가 되면 빨라지고, 체력 12／6 단계에서 경비병을 소환합니다. 예고는 2.4초, 한 번에 최대 2명이며 소환 간격은 최소 14초입니다. 멀리 있는 플레이어에게도 충격파를 사용합니다.
6. 승리 후 책상으로 다가가 모험 선언문에 서명하면 챕터가 끝납니다.

하트는 3개입니다. 실내에서 패배하면 보석을 유지하고 보스 방 입구에서 체력을 회복하여 재도전합니다. 일시 정지 중에는 시뮬레이션이 멈추며 창이 포커스를 잃으면 자동으로 정지합니다. 단일 챕터·세션 기반 게임으로 진행 자동 저장은 없습니다.

| 동작 | 조작 |
| --- | --- |
| 카메라 기준 이동 | WASD / 방향키 |
| 시점 / 확대·축소 | 왼쪽 클릭으로 공격과 마우스 고정, 휠로 거리 조절. 고정 불가 시 가운데 버튼 드래그 |
| 점프 / 달리기 | Space / Shift 길게 |
| 공격 / 차지 | 왼쪽 클릭 / J, 길게 눌러 차지 |
| 방어 / 활 조준 | 오른쪽 클릭 / F 길게 |
| 구르기 / 타깃 고정 | Ctrl 또는 K / Q |
| 무기 / 타깃 전환 | X / Tab |
| 상호작용 | E / 화면 상호작용 안내 클릭 |
| 카메라 초기화 / 일시 정지 | R / Esc(마우스 고정도 해제) |

검과 방패는 사용하지 않을 때 등에 보관합니다. 공격 시 오른손에 검을 들고 방어 시 왼손에 방패를 듭니다. 달리기, 공격, 구르기, 공격을 막는 동작은 스태미나를 소비합니다. 일반 점프는 무료이며 소비 동작을 멈추면 스태미나가 회복됩니다.

공격을 연속 입력하면 **내려 베기 → 왼쪽에서 오른쪽 베기 → 오른쪽에서 왼쪽 베기**로 이어집니다. 스태미나 소비는 8／9／12입니다. 시작 약 0.035초 후 다음 한 동작을 예약할 수 있으며, 첫 두 공격에는 종료 후 0.34초의 연계 시간이 있습니다. 마지막 공격은 추가 회복 시간이 필요합니다. 스태미나가 부족하면 공격하지 않으며 구르기는 연속 공격을 취소합니다.

어깨·팔꿈치·손목·허리·무릎의 관절 동작으로 공격을 표현합니다. 명중하면 짧은 히트스톱, 검 궤적, 불꽃, 충격음, 적의 경직과 카메라 흔들림이 함께 발생합니다. 일반 공격 경직은 약 0.56~0.60초, 마지막 공격은 약 0.95초입니다. 밀려나는 적은 장애물을 통과하지 않습니다.

공격을 길게 누르면 먼저 한 번 베고 차지를 시작합니다. 1.2초 후 금색 고리와 준비음이 나오며, 놓으면 360도 회전 베기를 사용합니다. 스태미나 26, 반경 3.8m이며 벽 가림 판정을 적용합니다. 일찍 놓기, 피격, 구르기, 점프, 일시 정지, 터치 취소는 차지를 취소합니다.

활은 한 발에 화살 1개와 스태미나 10을 소비합니다. 최대 차지는 0.85초, 발사 간격은 최소 0.48초입니다. 일반／최대 차지 피해는 1／2이며 보스는 회복 또는 소환 중에만 최대 차지 추가 피해를 받습니다. 화살은 연속 선분 충돌 검사로 벽과 가구에 막힙니다. 경비병은 화살 3개와 스태미나 보급을 떨어뜨리며 실내 재도전 시 화살이 최소 12개로 보충됩니다. 화살이 없어도 검으로 싸울 수 있습니다.

조준 표시는 적의 가슴을 따라가며 체력을 표시합니다. Q로 고정·해제하고 Tab 또는 상단 버튼으로 타깃을 바꿉니다. 타깃이 죽으면 주변의 살아 있는 적을 선택합니다. 마우스 이동만으로 고정이 풀리지 않으며 거리 변화에도 유예 시간이 있습니다. 가까이 조준할 때는 주인공을 반투명하게 표시합니다.

모바일은 왼쪽 스틱으로 이동하고 끝까지 밀면 달립니다. 오른쪽을 밀어 시점을 돌립니다. 공격·방어·점프·구르기의 간단한 버튼 묶음을 사용하며 HUD에서 무기와 타깃을 전환합니다. 활을 들면 방어가 조준으로 바뀝니다. 여러 손가락을 동시에 지원하며 손을 떼거나 터치가 취소되면 유지 입력을 해제합니다.

카메라는 거리 5~14, 시야각 55~80도, 감도 0.4~2배, 상하 반전, 명중 피드백을 설정하고 초기화할 수 있습니다. 세로 화면에서는 시야를 넓힙니다. 벽 근처에서는 거리를 줄이고 벗어나면 부드럽게 복원하며, 낮은 가구 위로 시점을 높이거나 주인공을 흐리게 표시합니다. [Epic의 카메라／Spring Arm 문서](https://dev.epicgames.com/documentation/en-us/unreal-engine/camera-components?application_version=4.27)를 참고했습니다.

상자, 레버, 회복 풀, 안내판, 벤치, 나무 상자와 상호작용할 수 있습니다. 상자와 회복 풀 보상은 한 번만 받습니다. 건물, 나무, 분수, 화단, 가구, 소품, 적에 충돌 판정이 있으며 발판 점프, 가장자리 낙하, 벽 따라 이동, 공격과 상호작용의 가림 검사를 지원합니다.

## 프로젝트 구조

| 경로 | 역할 |
| --- | --- |
| `src/game/simulation.ts` | 이동·충돌·전투·수집·퀘스트 상태 |
| `src/game/combat.ts` | 명중 타이밍과 관절 자세 |

| `src/components/SettingsPanel.tsx` | 언어·음량·카메라 설정 |
| `src/components/RangedCombat.tsx` | 조준·화살·소환 예고·보급 표시 |

## 검증

```bash
npm test
npm run build
# 먼저 다른 터미널에서 개발 서버를 실행하세요:
GAME_URL=http://127.0.0.1:4439 npm run test:e2e
```

이동, 연속 충돌, 착지, 카메라 회피, 공격 방향, 가림, 보상, 방어, 구르기, 스태미나, 연속 공격, 보스전, 재도전을 테스트합니다. 브라우저 시나리오는 장비 자세, 마우스 고정, 터치 조작, 챕터 완료를 검증합니다. 일부 시나리오는 개발 API로 시작 위치를 설정한 뒤 실제 입력을 사용하며, 순간이동 없이 전체 잔디밭 경로를 진행하는 테스트도 있습니다.

스크린샷은 `artifacts/`에 저장됩니다. Playwright는 기본적으로 로컬 Chrome을 사용합니다. Chromium을 쓰려면 `npx playwright install chromium`을 실행하고 `BROWSER_CHANNEL=chromium`을 지정하세요. 모바일 검증에는 390 × 844 화면, 동시 터치, 취소 입력 정리, 가로 넘침 확인이 포함됩니다.

## Blender 모델과 자료

- `assets/blender/build_trump.py` / `trump-n64.blend`: 금발, 정장, 빨간 넥타이, 깃발 핀과 이름 있는 관절을 갖춘 주인공. `public/models/trump-n64.glb`로 출력합니다.
- `build_adventure_props.py` / `adventure-props.blend`: 검, 방패, 상자, 레버, 나무 상자, 회복 풀. `hero-*.glb`, `adventure-*.glb`로 출력합니다.
- `build_bow.py` / `adventure-bow.blend`: 활, 화살통, 화살.
- `build_enemies_arena.py` / `enemies-arena.blend`: 경비병, 사령관, 실내 가구와 배경.
- `build_arrival_helicopter.py` / `arrival-helicopter.blend`: 문, 탑승 계단, 착륙 장치, 회전 날개가 있는 헬기.
- `public/title-screen.jpg`: 참고 영상에서 추출한 타이틀 이미지. 분리된 타이틀 자료와 출처는 `public/title/`에 있습니다.

Blender에서 `TRUMP_PROJECT_DIR`를 프로젝트 절대 경로로 지정한 후 모델링 스크립트를 실행하세요. 별도 장면에서 작업하여 기존 작업물을 보존합니다. `npm run assets:optimize`로 glTF Transform의 중복 제거, 정점 병합, 정리를 수행할 수 있습니다.

## 철갑 사령관과 집무실

[적과 실내 콘셉트](assets/concepts/enemies-and-oval-arena.png)를 바탕으로 경비병, 사령관, 호두나무 바닥, 상아색 벽 패널, 큰 창문, 붉은 커튼, 금테 카펫과 가구를 제작했습니다. 확장된 방의 중앙은 전투 공간으로 남기며 책장, 소파, 기둥, 책상에는 충돌체가 있습니다. 보스는 준비 동작 중 쉽게 경직되지 않지만 공격 후에는 빈틈이 생깁니다. 바닥 경고, 체력 바, 타깃 고정, 재도전을 지원합니다.

![집무실 보스전](artifacts/oval-boss-arena.png)

참고 영상에는 전체 전투·수집 규칙이 나오지 않습니다. 필요한 보석 수, 보상, 적, 승리 조건은 플레이 가능한 흐름을 위해 이 프로젝트에서 추가했습니다. 스크린샷에는 이전 개발 버전이 포함될 수 있습니다.
