# The Legend of Trump · 白宮奇遇記

[简体中文](README.md) · [繁體中文（香港）](README.zh-HK.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

基於 **React 19 + Three.js + React Three Fiber + TypeScript + Vite** 的可玩低多邊形冒險遊戲。

參考提供的視頻中的金髮西裝角色、第三人稱視角、白宮外景與辦公室、愛心／翡翠／小地圖界面，製作了一個可獨立運行的冒險章節。標題頁參考用户提供視頻的劍盾 Logo、金色字形和暗紋背景。人物通過 Blender MCP 重新建模並導出 GLB，場景與音效由代碼生成；沒有打包整段原視頻或原遊戲模型。配樂包含 Suno 生成曲目及可選的《時之笛》原版曲目，來源見 [音頻説明](public/audio/README.md)。

## 啓動

需要 Node.js 22.12+（或 24/26）及支持 WebGL 2 的現代瀏覽器。

```bash
npm ci
# 在本機工作區自動調用端口管理器分配端口：
npm run dev
# 在其他機器上，明確指定一個空閒端口：
PORT=5173 npm run dev
```

終端會打印實際訪問地址。當前開發環境使用端口管理器的 `worktree-frontend` 池，首次驗證地址為 `http://127.0.0.1:4439/`。啓動腳本不覆蓋已有監聽進程。

```bash
npm run build
PORT=5173 npm run preview
```

`dist/` 是可部署的靜態站點。資源使用相對路徑，可放在子目錄中。遊戲無需後端；Google Fonts 不可用時使用系統字體回退。

## 設置與語言

標題頁和暫停菜單的「設置」支持簡體中文、English、日本語、한국어，以及總聲音開關、音樂／音效獨立音量、Suno／時之笛配樂來源和鏡頭選項。設置自動保存在本機瀏覽器，遊戲進度不隨之存檔。兩套配樂均讀取 `public/audio/` 內的本地文件。

## 玩法

1. 在南草坪收集 **8 枚翡翠**。沿噴泉兩側探索，陶罐中也有翡翠。
2. 揮劍擊碎陶罐，每個陶罐獲得 2 枚翡翠。木箱也可破壞；發條守衞需要三次命中，會先蓄力再攻擊，可用盾牌正面格擋或閃避；受擊會中斷蓄力、後仰硬直並被擊退。
3. 集齊後到白宮大門前交互，進入橢圓形辦公室。
4. 打開東側旅行寶箱獲得冒險弓和 16 支箭；花園寶箱另提供 12 支箭。按 X 切換劍盾 / 弓箭，長按左鍵拉弓、鬆開射擊，右鍵精瞄。
5. 擊敗室內 Boss「鐵甲統領」：金色橫掃可正面格擋，紅色重砸需要閃避，擴散衝擊波可以跳過。半血後進入更快的過載階段；12 / 6 血階段各召喚一波衞兵，2.4 秒預警，每波最多兩名，兩波至少相隔 14 秒。遠距離也會釋放衝擊波。
6. 勝利後走近書桌並簽署冒險宣言，完成章節。

三顆愛心耗盡後可以重試；室內失敗會在 Boss 房間入口恢復滿血重新挑戰，保留翡翠；暫停時模擬停止，窗口失焦自動暫停。當前為單章節、單次會話遊戲，無自動存檔。

| --------------- | --------------------------------------------- |
| 按鏡頭方向移動  | WASD / 方向鍵                                 |
| 鼠標視角 / 縮放 | 左鍵攻擊並鎖定鼠標 / 滾輪；無法鎖定時中鍵拖動 |
| 跳躍 / 衝刺     | Space / 按住 Shift                            |

| 閃避 / 鎖定目標 | Ctrl 或 K / Q                                 |

劍與盾不用時背在角色身後，攻擊時劍切換到右手，格擋時左手舉盾、右手保持持劍，連招銜接期間保持手持，結束後自動揹回。衝刺、攻擊、閃避和承受格擋消耗體力，停止消耗後恢復。

連續點擊左鍵、按 J 或點擊手機攻擊按鈕，可以打出 **下劈 → 左向右橫斬 → 右向左橫斬**。起手後約 0.035 秒即可預輸入下一式，每次只緩存一式；前兩式收招後還有 0.34 秒銜接窗口，停頓過久從第一式重來。第三式結束有額外收招，不能無限連發。三式分別消耗 8 / 9 / 12 體力；體力不足不會強制出招，閃避會中斷當前連招。

動作由肩、肘、腕、腰和膝關節協同驅動，劍綁定右手腕，盾綁定左手腕。命中時有短促停頓、劍光、敵人閃亮與受擊後仰；普通斬擊硬直約 0.56–0.60 秒，第三式橫斬約 0.95 秒。擊退受場景碰撞約束，敵人硬直結束後恢復行動，最後一擊有倒地退場過程。

左鍵第一次點擊場景就會攻擊，同時申請鼠標鎖定；瀏覽器拒絕鎖定時仍可攻擊。左鍵連點與 J 使用同一套連招邏輯，暫停菜單或其他界面按鈕不會觸發攻擊。

暫停菜單的「視角與鼠標設置」支持鏡頭距離 5–14（默認 9.5）、垂直視野 55–80°（默認 60°）、靈敏度 0.4–2 倍，以及垂直反轉。滾輪也能調距離，設置保存在本機瀏覽器；可一鍵恢復默認。豎屏會自動擴展垂直視野以保持橫向可見範圍。

相機遇牆及時收縮、離牆平滑恢復；先嚐試抬高鏡頭越過低傢俱，守衞不參與相機阻擋。牆邊無法保持距離時角色淡出，避免身體遮住畫面，同時保留牆體避障。實現參考了 [Epic 的第三人稱 Camera / Spring Arm 説明](https://dev.epicgames.com/documentation/en-us/unreal-engine/camera-components?application_version=4.27)，具體距離和視野按本項目場景調整。

手機和平板使用左側虛擬搖桿移動、右側空白區域滑動視角，以及攻擊、跳躍、閃避、鎖定、衝刺和防禦按鈕；支持多指同時操作。衝刺與防禦需要按住，鬆手或觸控取消即釋放。

花園新增寶箱、開門機關、草藥、告示牌、休息長椅和可破壞木箱。寶箱與草藥只能領取一次，機關開啓花園鐵門。碰撞包含建築、樹木、噴泉、花壇、傢俱、道具和守衞；角色支持跳上平台、邊緣墜落和牆邊滑動，攻擊與交互檢查遮擋，相機遇牆縮短距離。

弓箭每次消耗 1 支箭與 10 體力，0.85 秒滿弓，射擊間隔至少 0.48 秒。普通箭傷害 1，滿弓傷害 2；Boss 只有收招或召喚時承受滿弓額外傷害。飛箭用連續線段檢測命中，牆與傢俱能擋箭。倒下的守衞掉落 3 支箭和體力補給；室內重試至少恢復 12 支箭。箭矢用盡仍可切回劍盾完成戰鬥。

鎖定準星跟隨敵人胸口並顯示生命值，Tab 或頂部按鈕切換目標，目標死亡後選擇附近存活目標。鼠標轉動不會誤解除鎖定，距離變化有緩衝；瞄準貼身敵人時人物半透明，避免擋住目標。手機使用武器切換按鈕以及“拉弓·射箭”按鈕，右側“精瞄”替代持弓時的防禦。

白宮室內擴至約 37 × 36，傢俱保持正常比例，補充柱頭、柱槽、牆板、肖像、書櫃、旗幟與頂部格柵；中央留出 Boss 與衞兵的戰鬥空間。

## 項目結構

- `src/game/simulation.ts`：獨立於渲染器的移動、碰撞、戰鬥、收集和任務狀態機。
- `src/components/RangedCombat.tsx`：屏幕鎖定準星、飛箭、召喚預警和補給顯示。
- `src/game/combat.ts`：三段攻擊的共享命中時序與關節姿勢插值。
- `src/game/input.ts`：鍵盤、鼠標鎖定、搖桿與失焦處理。
- `src/game/world.ts` / `collision.ts`：共享交互位置、碰撞體、分步滑動、落地與射線遮擋。
- `src/components/InteractiveProps.tsx`：寶箱、機關與採集物模型及狀態動畫。
- `src/game/audio.ts`：用户手勢激活後的 Web Audio 合成音效。
- `src/components/World.tsx`：白宮建築、花園、噴泉與辦公室。
- `src/components/Character.tsx`：Blender GLB 加載，以及行走、揮劍和坐姿書寫動畫。
- `src/components/Scene.tsx`：R3F 場景、相機、實體同步及模擬步進。
- `src/components/Hud.tsx`：DOM 界面、小地圖及觸屏操作。
- `src/App.tsx`：標題、暫停、指南、對話和結算。

高頻遊戲狀態保存在模擬實例中，DOM 以低頻率刷新，角色和相機通過 `useFrame` 同步。模擬對大幀間隔分步處理，避免穿透與明顯的低幀率減速。為了方便本地端到端測試，僅開發環境暴露 `window.__game`、`window.__scene` 和 `window.__camera`，生產構建不暴露。

## 驗證

```bash
npm test
npm run build
# 先在另一終端啓動開發服務器；默認使用本機 Chrome：
GAME_URL=http://127.0.0.1:4439 npm run test:e2e
```

- 單元測試覆蓋鏡頭相對移動、連續碰撞、跳台落地、相機避障、方向與遮擋攻擊、機關與一次性獎勵、盾牌和閃避、體力、通關與重開。
- Playwright 覆蓋劍盾揹負／手持切換、跳躍、鼠標鎖定與格擋、相機避牆、互動與完整通關。
- 移動端驗證 390 × 844 視口，三指同時移動、衝刺與轉動視角，防禦取消清理及無橫向溢出。
- 測試中用開發接口設置中間場景位置，隨後通過真實輸入與模擬驗證交互，並非全程自動尋路。
- 截圖保存在 `artifacts/`。測試配置默認使用本機 Chrome，也可設置 `BROWSER_CHANNEL=chromium` 並先執行 `npx playwright install chromium`。

視頻中沒有展示完整收集和戰鬥規則；陶罐獎勵、發條守衞、翡翠門檻和通關條件是本項目為構成可玩流程添加的設計。畫面按照視頻改為飽和藍天、低多邊形人物和 N64 風格的紅心、綠／藍／黃色操作按鈕。本項目為非官方創作。

## Blender 模型與素材

- `assets/blender/build_bow.py` / `adventure-bow.blend`：反曲弓、箭袋與羽箭模型。
- `assets/blender/build_enemies_arena.py`：衞兵、統領與擴建室內佈景。
- `assets/blender/trump-n64.blend`：獨立的人物建模源文件。
- `assets/blender/build_trump.py`：可復現的 Blender 建模腳本，包含稜面頭部、金髮、面部五官、西裝紅領帶、旗幟胸針和肩、肘、腕、髖、膝及腰部關節層級。
- `public/models/trump-n64.glb`：約 97 KB，13 個網格對象、約 1,318 個三角形，保留可動畫的命名軸；無外部紋理依賴。
- `assets/blender/adventure-props.blend` / `build_adventure_props.py`：獨立劍、盾、寶箱、機關、木箱與草藥源文件及生成腳本。
- `public/models/hero-*.glb` / `adventure-*.glb`：六個輕量模型，寶箱與機關保留可動畫軸。
- `public/title-screen.jpg`：從用户提供視頻第 2 秒提取的標題畫面，作為靜態標題頁素材。

重建時在 Blender 中設置 `TRUMP_PROJECT_DIR` 環境變量為項目絕對路徑，再運行建模腳本。腳本創建獨立場景，僅導出當前人物場景，保留現有 Blender 工程。隨後在項目目錄執行 `npm run assets:optimize`，通過 glTF Transform 去重、焊接和清理。

瀏覽器測試覆蓋鍵鼠、手機多點觸控、通關、三段關節連招及 Boss 戰。單元／資產測試覆蓋連招輸入緩存、體力與取消、單次命中、敵人硬直、Boss 完整戰鬥、開門伸梯時序和模型關節。測試包含無瞬移的完整草坪路線驗證；瀏覽器用開發接口定位部分測試場景，再以真實鍵鼠和多點觸控操作驗證。

## 鐵甲統領與橢圓廳

先生成 [敵人與室內概念圖](assets/concepts/enemies-and-oval-arena.png)，再用 Blender MCP 製作可動畫的守衞、鐵甲統領，以及胡桃木地板、象牙色牆板、落地窗、酒紅窗簾、金邊地毯和傢俱。中央保留戰鬥空間；書櫃、沙發、柱子與書桌都有對應碰撞體。

- 源文件：`assets/blender/enemies-arena.blend`；生成腳本：`assets/blender/build_enemies_arena.py`。
- 模型：`palace-sentinel.glb`、`iron-chancellor.glb`、`oval-arena.glb`，分別約 59、69、837 KB。
- 普通敵人保留受擊硬直；Boss 蓄力時有霸體、收招時有進攻破綻，終結技能造成更強硬直。Boss 戰支持鎖定、血條、地面預警與失敗重試。
- 持劍待機和格擋時劍刃保持直立，攻擊期間由關節動作驅動。
- 直升機有持續發動機和旋翼拍擊合成音效，隨接近／遠離淡入淡出，跳過片頭時靜音。落地開門時伸出登機梯，梯子就位後人物下機，離開前收梯關門。

![橢圓廳 Boss 戰](artifacts/oval-boss-arena.png)

室內大廳現約 30 × 28 米，長寬比初版擴大 65%，傢俱保持原尺寸並向周邊移動。室內鏡頭在個人距離設置基礎上增加 1.5 米、視野增加 5°；焦點向前偏移，鎖定 Boss 時平滑取雙方之間的位置，減少人物遮擋與近戰轉向突變。傢俱、牆體、入口、書桌交互、小地圖和結算鏡頭已同步調整。

按住鼠標左鍵、J 或手機「攻擊」：先立即出刀，再進入蓄力。蓄滿 1.2 秒會亮起金色光環並響起提示音，鬆開釋放 360° 旋轉斬；消耗 26 體力，半徑 3.8 米，普通敵人與 Boss 各受到一次 2 點傷害。配有聚攏光點、蓄力進度、雙層環形劍光和擊退火花；攻擊仍檢查牆體遮擋。提前鬆開、受擊、閃避、跳躍、暫停或觸控取消會取消蓄力。
