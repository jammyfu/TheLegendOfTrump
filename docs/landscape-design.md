# 城市天际线与草坪景观

延续白宫历史布局的低多边形风格。新增街区是环境美术布景，不代表逐栋实测的华盛顿建筑。

- 天空层：环绕地平线的淡色城市剪影，使用雾色降低对比度。
- 城市层：两层低层街区，包含窗格、檐口、屋顶阁楼、烟囱和行道树；保留南侧椭圆草坪与华盛顿纪念碑的轴线视野。
- 主场景：66 株新增树木、8 组花坛、8 张长椅、12 盏路灯、6 组景石；增加中央步道、支路、休憩铺地和草坪修剪条纹。8 只飞鸟提供轻微动态。
- 碰撞和 Blender 模型共用 `src/game/landscape-layout.json`。中央行走路线、降落区、营地和宝箱保留通路。
- 城市窗口用平面几何实现，静态物件按区域和材质合并，资产共 34 个网格；鸟群采用低面数几何，不额外增加动态光源。

重建：通过 Blender MCP 执行 `assets/blender/build_landscape.py`，再执行 `node scripts/optimize-landscape.mjs`。源场景保存在 `assets/blender/park-landscape.blend`。
